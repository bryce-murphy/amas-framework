### §2.(v) §8.2-timing propagation + sweep-scope-definition pitfall (additional observation from post-PR arc)

- **Observation**: after a canonical fix to a discipline's timing/trigger, every surface that *paraphrases* that discipline must be updated — and the target surface set must be enumerated by **grep on the discipline's keywords**, not a hand-listed set of "instruction files." Hand-listing systematically under-counts: the pass-11 sweep (4 instruction files) missed the usage-guide quick-reference (L404), the handoff-template pre-flight note (L149), and the §8.2 principle intro (L161) — all caught at passes 12–13 by Codex and the Gate-A sweep respectively.
- **This-cycle evidence**: the §8.2-timing propagation class required 3 successive passes (11/12/fold-in) to exhaust because each pass swept a differently-scoped surface set. The grep-enumerated approach (keyword: `pre-flight | before (creating|the) branch | §8.2`) found the principle intro residual that even the pass-12 Codex pass missed. **Lesson closed**: use `grep -rniE <keywords> <all-canonical-surfaces>` to enumerate the surface set; classify each hit; confirm zero timing-prescriptive laggard before declaring the class exhausted.
- **Observe-then-canonicalize status**: strong first-evidence (3 recurrences within one cycle's propagation sweep); candidate for the three-ring gate's **surface-enumeration sub-rule**. Registration only; not canonicalized.
